# Laboratories – BVRIT HYDERABAD College of Engineering for Women

Source: https://bvrithyderabad.edu.in/information-technology/laboratories

Department has well equipped state of art laboratories with the latest configuration systems. Systems are connected via local area network to the Domain Server (BVRITH). Students are encouraged to engage themselves in getting practiced with laboratory experiments in their leisure hours by keeping the labs open even after the college hours.

ODD SEMESTER :

C++Programming Lab: Students will be able to develop applications for a range of problems using object-oriented programming techniques and C++ programming language can be used in application and system programming so the Students will choose their area of interest of software development

Android Application Development Lab: Students will develop User Interface applications, intents for communicating data among activities, notifications, fragments, applications related to user registration and login using the concept of files, SQLite for connecting to database and storing data in android environment.

EVEN SEMESTER :

Java Programming Lab: Students will be able to write programs in Java using Text Editor, Eclipse and in addition to regular lab sessions CodeTantra tool is available to the students which help them to improve their Fundamental concepts and Syntax.

Mobile Application Development Lab: Students will study the concepts of mobile application development in Android operating system environment. They can build some useful mobile applications.

Data Structures Lab: Students will be able to develop skills to design and analyze simple linear and non linear data structures. It strengthens the ability to the students to identify and apply the suitable data structure for the given real world problem. It enables them to gain knowledge in practical applications of data structures.

Web Scripting Languages Lab: Students will be able to understand the differences between Scripting languages and programming languages ,able to gain some fluency programming in Ruby, Perl, TCL

Database Management System Lab: Students will be able to design and Implement a Database schema for given problem, apply the normalization techniques for development of application software to realistic problems, Formulate Queries using SQL DML/DDL/DCL Commands.

Scripting Languages Lab: Students will be able to understand the differences between Scripting languages and programming languages ,able to gain some fluency programming in Ruby, Perl, TCL

Computer Networks & Web Programming Lab:

Students will study the various layers of OSI Models, apply appropriate algorithms for finding Shortest Root between nodes, Configure the Routing Table and Encryption & Decryption concepts etc.on Linux Environment,Build dynamic web pages using JavaScript (Client side programming). Create XML documents and Schemas.

Ethical Hacking Lab: Students will have hands on experience on various hacking techniques used to identify the vulnerabilities and exploit the networks using tools like NMap, Burp suite, Jcrypt, Sql injection and Password cracking tools. Thus students will learn to safeguard computer system and mobile environments from hacking, phishing and other security related threats.

Network Programming Lab: Students with get hands of experience on Unix system calls, Unix Inter Process communication, Remote Procedure Call, Socket programming, Process Synchronization.

Software Engineering Lab: Students will be able to understand software engineering methodologies involved in the phases for project development. They can also gain knowledge on open source tools such as StarUML/UML Graph/Topcased for implementing software engineering methods.

Python Programming Lab: Students will exercise on Python language programming to solve some problems which are of real time. As the AI and ML trend is currently active, they can get expertise in Python programming which is key language in this domain.

Compiler Construction Lab: Students will be able to write a compiler using a variety of software tools and modify existing components of a compiler.

Software Testing Methodologies Lab: Students will be able to analyze and design test cases using different testing techniques and execute how to do performance testing using testing tools

IT Workshop & Microprocessor Lab: Students will gain knowledge on usage of Productivity Tools including Word, Excel, Power Point Presentations and Latex, Internet & World Wide Web, search engines along with hardware troubleshooting and assembling and disassembling of their personal computer. And they will also acquire the knowledge of assembler directives, assembly language programming of 8086.

Internet of Things Lab: Students will be able to understand the application areas of IOT, realizes the revolution of Internet in Mobile Devices, Cloud & Sensor Networks & understands the building blocks of Internet of Things and characteristics.

Operating Systems Lab: Student will be implementing the concepts such as scheduling, deadlock management, file management, and memory management. They shall also implement system calls, perform inter process communication between two processes, design and solve synchronization problems using the C language in Ubuntu.

Embedded Systems & Internet of Things Lab: Students will be able to Implement an architectural design for IoT for specified requirement, solve the given societal challenge using IoT.

Mini Project: Students will be able to practice acquired knowledge within the chosen area of technology for project development. Identify, discuss and justify the technical aspects of the chosen project with a comprehensive and systematic approach.

Seminar: Students will be able to review, prepare and present technological developments.

Hobby Project: Students will be able to pursue their hobbies and interests through projects

Project Work: Students will be able to design engineering solutions to complex problems utilising a systems approach and demonstrate the knowledge, skills and attitudes of a professional engineer.
